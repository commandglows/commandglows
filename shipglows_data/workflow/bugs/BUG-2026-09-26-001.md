# Bug Record: BUG-2026-09-26-001

## Summary

- Current status: `fixed-pending-verify`
- Severity: `medium` in a debug-only prototype; the missing behavior is essential to the intended feature.
- Owner: Diane

## Reproduction

- Preconditions: run the Windows debug app through the managed Doppler launcher; sign-in is not required.
- Steps:
  1. Select **Ouvrir le post-it de démonstration** on the sign-in screen.
  2. Activate an ordinary browser or editor window in front of CommandGlows.
  3. Inspect the post-it stacking and French text.

## Expected Behavior

The post-it remains above ordinary windows without activating or changing the main CommandGlows window. Its title and snippet accents render correctly.

## Observed Behavior

Other windows cover the post-it. The screenshot also shows corrupted accented characters in its native title and snippet.
